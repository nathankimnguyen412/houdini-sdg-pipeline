# Dataset

The synthetic datasets generated by this pipeline are hosted on Hugging Face. All four training versions are published to document the full iterative development process.

**Hugging Face:** [nathankimnguyen412/houdini-lego-sdg](https://huggingface.co/datasets/nathankimnguyen412/houdini-lego-sdg)

---

## Dataset Versions

| Version | Images | Classes | Distractors | DR Axes | Description |
|---------|:------:|:-------:|:-----------:|:-------:|-------------|
| v1 | 1,000 | 1 | No | 12 | Baseline pipeline, single class |
| v2 | 1,000 | 1 | Yes | 25+ | Distractors added, 13 additional textures |
| v3 | 3,000 | 7 | Yes | 25+ | 7-class scale-up, 3K images |
| v4 | 7,000 | 7 | Yes | 25+ | Full-scale primary dataset |

Each version includes:
- 512×512 PNG renders (beauty pass)
- 512×512 Cryptomatte EXR renders
- `annotations.json` in COCO format (bounding boxes + instance segmentation masks)

## COCO Annotation Format

All annotation files follow the COCO instance segmentation format:
```json
{
  "images": [
    {
      "id": 0,
      "file_name": "render_0000.png",
      "width": 512,
      "height": 512
    }
  ],
  "annotations": [
    {
      "id": 0,
      "image_id": 0,
      "category_id": 1,
      "bbox": [x, y, width, height],
      "segmentation": [[x1, y1, x2, y2, ...]],
      "area": 1842.5,
      "iscrowd": 0
    }
  ],
  "categories": [
    {"id": 1, "name": "1x1_plate", "supercategory": "plate"}
  ]
}
```

Annotations were generated automatically by the pipeline using Cryptomatte AOV extraction. No manual annotation was performed on the synthetic training data.

## Evaluation Data

The complete real-world evaluation data used to compute all AP scores is included in this folder.

### Photos

`eval_photos/` contains the 90 real-world photographs used for evaluation, center-cropped and resized to 512×512:

- `eval_photos/controlled/`: 30 images (eval_000.png through eval_029.png)
- `eval_photos/diverse/`: 60 images (eval_000.png through eval_059.png)

**Controlled set:** Lego bricks photographed on a single surface with consistent overhead lighting and a roughly 45° camera angle. Designed to measure performance under favorable, synthetic-like conditions.

**Diverse set:** Lego bricks photographed across multiple environments including kitchen counters, carpet, outdoor concrete, gravel, grass, and stainless steel, with varying lighting, angles, distances, and background clutter. Designed to stress-test the sim-to-real domain gap.

### Ground Truth Annotations

`eval_annotations/` contains two sets of COCO ground truth annotations, one per model family:
```
eval_annotations/
  1class/
    controlled_annotations.json    (30 images, 1 class: lego_brick)
    diverse_annotations.json       (60 images, 1 class: lego_brick)
  7class/
    controlled_annotations.json    (30 images, 7 classes)
    diverse_annotations.json       (60 images, 7 classes)
```

All annotations were produced using SAM 3 in CVAT with manual correction applied to cases involving occlusion, reflective surfaces, irregular geometry, and similar edge cases where SAM 3 produced inaccurate masks.

Use the `1class/` annotations to reproduce v1 and v2 AP scores. Use the `7class/` annotations to reproduce v3 and v4 AP scores. Both annotation sets reference the same photo files in `eval_photos/`.

To reproduce any evaluation run:
```python
# Update paths in eval_lego.py to point to eval_photos/ and the appropriate
# annotation set, then run:
python eval_lego.py
```

## Notes

- All synthetic images are rendered at 512×512 to match the evaluation photo resolution after preprocessing with `resize_photos.py`.
- Synthetic annotations were extracted automatically from Cryptomatte AOVs rendered by Karma XPU. Each annotation includes a pixel-accurate segmentation polygon, bounding box, and area.
